# Akses Berkas dan Folder

Istilah untuk menentukan siapa yang dapat menemukan dan membuka dokumen maupun folder di portal.

## Bahasa akses

**Publik**:
Tampil dalam daftar portal dan dapat dibuka oleh siapa pun.

**Akses via Tautan**:
Tidak tampil dalam daftar portal, tetapi dapat dibuka oleh siapa pun yang memiliki tautan. PIN dapat ditambahkan sebagai perlindungan opsional.
_Avoid_: Hanya Tautan, Tautan Rahasia

**Privat**:
Dokumen yang hanya dapat dibuka oleh administrator, termasuk bila tautannya diketahui. Folder tidak memiliki status Privat.

**PIN**:
Kode verifikasi opsional bagi berkas atau folder berstatus Akses via Tautan.
_Avoid_: Password

## Identitas dan tampilan

**SIMPUN**:
Nama aplikasi, kependekan dari Sistem Informasi Manajemen Publikasi Untuk Naskah.

**Gaya tema global**:
Gaya visual yang dipilih administrator dan diterapkan sama untuk seluruh pengunjung serta halaman admin.
_Avoid_: Tema pengunjung, tema per sesi

**Mode warna**:
Variasi Terang atau Gelap. Admin menentukan default, sedangkan pengunjung boleh menyimpan pilihan mode lokal di browser.
